# BMW Sales Report | Power BI

An interactive Power BI report analyzing BMW sales from 2010 to 2024, with KPI cards, charts, and slicers for exploring sales by fuel type, price category, model, and region.

## Objective

Explore BMW sales performance over time and compare how different models, regions, fuel types, and price bands contribute to sales.

## Report Features

- **4 KPI cards** summarizing key sales figures
- **4 charts:** line chart, pie chart, 100% stacked bar chart, and 100% stacked column chart
- **4 slicers:** fuel type, price category, model, and region
- **Custom Price Category field** that segments sales into price bands, so sales classification can be compared across models and regions

## Key Questions Answered

- How have sales trended from 2010 to 2024?
- How do sales split by fuel type?
- How do price categories compare across models and regions?
- Which models and regions perform best?

## Tools Used

- Power BI Desktop
- DAX (custom Price Category field)

## Dataset

BMW sales data, 2010 to 2024. Source: ADD_SOURCE (for example, Kaggle link).

## How to Use

1. Download the `.pbix` file from this repo.
2. Open it in Power BI Desktop.
3. Use the slicers to filter by fuel type, price category, model, and region.
